# Property Listing & Rental Platform

A full-stack property listing and rental platform built using **Node.js, Express.js, MongoDB, Passport.js, Mapbox, and Bootstrap**.

## Overview

This project was designed and developed end to end, from requirements and design through coding, testing, and production deployment. It uses Express.js REST APIs and MongoDB for the application backend.

## Features

- Full-stack property listing and rental experience
- REST APIs built with Node.js and Express.js
- MongoDB for data persistence
- Passport.js authentication
- Role-Based Access Control (RBAC)
- Joi input validation
- Mapbox integration
- Responsive UI styled with Bootstrap

## Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** Passport.js
- **Validation:** Joi
- **Maps:** Mapbox
- **Frontend Styling:** Bootstrap

## Security

Passport.js authentication, role-based access control, and Joi input validation help protect user data, restrict unauthorized access, and reduce invalid submissions.
